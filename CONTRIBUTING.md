# Guia de Contribuição
Obrigado por querer contribuir com este repositório! Toda contribuição ajuda a comunidade a usar recursos do Git com mais eficiência e intenção.

## Tipos de contribuição
O conteúdo rico deste repositório está contido em uma Wiki - https://github.com/vinicius-stutz/ai/wiki. Todo envio deve ser realizado pela própria plataforma do Github pelo proprietário do repositório.

## Antes de começar
1. **Verifique se já existe** algo semelhante no repositório. Busque pelo tema antes de criar um arquivo novo.
2. **Teste seu comando git** — contribua apenas com conteúdo que você já usou e validou.
3. **Prefira qualidade a quantidade** — um comando bem descrito vale mais do que dez genéricos.
4. **Não inclua dados pessoais** — substitua por variáveis (`{{VARIAVEL_AQUI}}`).

## Como contribuir
1. Abra ou um [Pull Request](../../pulls) ou uma [Issue](../../issues);
2. Use o título mais adequado (se não souber qual usar adicione **[Categoria]**);
3. Descreva o conteúdo, bem formatado, respeitando a semântica;
4. Submeta o conteúdo e aguarde a revisão e a publicação na Wiki.
